# File Processing Tools

A comprehensive web application built with Next.js that provides various file processing tools including PDF manipulation, image editing, video conversion, and more.

## Features

- **PDF Tools**: Compress, merge, split, rotate, convert to/from images, PPT, Word
- **Image Tools**: Compress, convert, edit, resize
- **Video Tools**: Convert, extract audio, trim
- **Document Tools**: PPT to PDF, Word to PDF
- **Spreadsheet Tools**: CSV to Excel, Excel to CSV
- **Data Tools**: JSON to CSV, text extraction
- **Archive Tools**: Files to ZIP

## Prerequisites

- Node.js (version 18 or higher)
- pnpm package manager

## Installation

1. Clone the repository:
```bash
git clone https://github.com/kungfupanda420/not_ilovepdf
cd not_ilovepdf
```

2. Install dependencies:
```bash
pnpm install
```

## Running the Application

Start the development server:
```bash
pnpm dev
```

The application will be available at `http://localhost:3000`.

## Building for Production

1. Build the application:
```bash
pnpm build
```

2. Start the production server:
```bash
pnpm start
```

## Linting

Run the linter to check code quality:
```bash
pnpm lint
```

## Technologies Used

- **Framework**: Next.js
- **UI Components**: Radix UI
- **Styling**: Tailwind CSS
- **Video Processing**: FFmpeg
- **Deployment**: Vercel
